## Situation

Clockwork Agency delivers enterprise applications across banking, automotive, retail, hospitality, and other industries. Across my tenure, technical delivery covered **98 projects** across 13 industries. New projects typically took about **2 weeks** to set up. Some applications operated within **ISO 27001** scoped environments.

## Task

As **Senior Software Developer / Team Lead**, I was responsible for:

- Creating and maintaining the agency's standardized CMS framework (Umbraco)
- Leading engineering teams of up to 13 developers through 98 enterprise projects
- Establishing code review practices and CI/CD pipelines
- Leading security remediation across banking and government projects
- Mentoring junior developers in clean code and modern development practices
- Delivering projects for clients including TOFAŞ/FIAT, Arçelik, and Ziraat Bank
