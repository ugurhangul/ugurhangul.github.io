> **Role:** Senior Software Developer & Team Lead
> **Evidence:** 106 commits (Yeşilay), 29 commits (Ziraat), 44 commits (FashionTV), 26 commits (Spectrum Sinema), 11 commits (Sural), 6+ commits (Arçelik), plus framework repos (v10→v15) — spanning 98 enterprise projects across 13 industries

## Situation

Clockwork Agency is an Istanbul-based digital agency delivering enterprise websites and applications for major Turkish brands. When I joined, the agency was scaling rapidly from ~20 to **98+ projects** across 13 industries (automotive, banking, energy, hospitality, healthcare, consumer electronics, NGOs). Each project was built independently, leading to duplicated effort, inconsistent code quality, and **2-week setup times** for new projects. The team had no standardized framework, no code review process, and limited CI/CD practices. Some clients (banking, government) required **ISO 27001** compliance.

## Task

As **Senior Developer and Team Lead**, I was responsible for:

- Creating and maintaining the agency's standardized CMS framework (Umbraco)
- Leading the team through 98 enterprise projects with zero missed deadlines
- Establishing code review culture, testing patterns, and CI/CD pipelines
- Achieving ISO 27001 security compliance across the portfolio
- Mentoring junior developers in clean code and modern development practices
- Delivering projects for top-tier clients: Fiat, Alfa Romeo, Arçelik, Ziraat Bankası, Kuveyt Türk, Yeşilay, Zorlu Enerji
